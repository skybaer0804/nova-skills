# Agent A2A (Agent-to-Agent Protocol)

## Overview
A2A is a Linux Foundation standard that allows agents built with different frameworks or vendors to communicate without exposing their internal implementation. If MCP is agent↔tool, A2A is agent↔agent.

**Before using this skill, verify that A2A is needed via `agent-protocol-design`.**

## Core Concepts

| Concept | Description |
|---------|-------------|
| **AgentCard** | `/.well-known/agent-card.json` — declares agent capabilities and endpoints |
| **Task** | Unit of work between agents (submitted → working → completed/failed) |
| **Message** | Individual message within a Task (text, file, data) |
| **Artifact** | Output produced after a Task completes |

```
Client Agent                      Server Agent
     │  GET /.well-known/agent-card.json  │  ← agent discovery
     │◄──────────────────────────────────│
     │  POST /  (tasks/send)              │  ← task request
     │──────────────────────────────────►│
     │  result returned (sync) or SSE (streaming)  │
     │◄──────────────────────────────────│
```

## Python — A2A Server (Google ADK)

```python
# pip install google-adk a2a-sdk
from google.adk.agents import Agent
from google.adk.a2a.utils.agent_to_a2a import to_a2a
import uvicorn

pricing_agent = Agent(
    model="gemini-2.0-flash",
    name="pricing_agent",
    instruction="Return current wholesale prices for requested items.",
)

# Expose ADK agent as an A2A server
# AgentCard auto-generated: http://localhost:8001/.well-known/agent-card.json
app = to_a2a(pricing_agent, port=8001)

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8001)
```

## Python — A2A Client

```python
from a2a.client import create_client
from a2a.types import Message, Part, TextPart, Role
import asyncio

async def ask_pricing_agent(item: str) -> str:
    async with await create_client("http://pricing-agent:8001") as client:
        message = Message(
            role=Role.user,
            parts=[Part(root=TextPart(text=f"Price of {item}?"))],
        )
        async for event in client.send_message(message):
            if isinstance(event, tuple):
                task, _ = event
                if task.artifacts:
                    return task.artifacts[0].parts[0].root.text
            else:
                return event.parts[0].root.text

asyncio.run(ask_pricing_agent("salmon"))
```

## TypeScript — A2A Client (Next.js API Route)

```typescript
// app/api/price/route.ts
// npm install @a2a-js/sdk
import { ClientFactory } from '@a2a-js/sdk/client'

export async function POST(req: Request) {
  const { item } = await req.json()

  const factory = new ClientFactory()
  const client = await factory.createFromUrl('http://pricing-agent:8001')

  // Discover AgentCard then send message
  const task = await client.sendMessage({
    message: {
      role: 'user',
      parts: [{ type: 'text', text: `Price of ${item}?` }],
    },
  })

  return Response.json({ price: task.artifacts?.[0]?.parts[0]?.text })
}
```

## AgentCard Structure

Format of `/.well-known/agent-card.json` auto-generated by `to_a2a()`:

```json
{
  "name": "Pricing Agent",
  "description": "Returns wholesale prices",
  "url": "http://pricing-agent:8001",
  "version": "1.0.0",
  "capabilities": { "streaming": true },
  "skills": [
    { "id": "get_price", "name": "Get Price", "description": "Returns current price" }
  ]
}
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Using `/.well-known/agent.json` URL | Correct path is `/.well-known/agent-card.json` |
| Implementing raw JSON-RPC directly | Use `a2a-sdk` / `@a2a-js/sdk` |
| Hardcoding URL without AgentCard discovery | Let `create_client()` / `createFromUrl()` fetch the AgentCard |
| Calling another agent's internals directly | Communicate only through the A2A protocol |
